## Inspired from the Research work done during my Master Thesis on QUIC 

- **What is QUIC**: Quick UDP Internet Connections , a web transport protocol built on top of UDP which delivers low latency, high throughput features while being highly secured and reliable.
- **How beneficial is QUIC**: Since it is a Web Transport protocol , it can improve the web application performance and its underlying challenges.
- **Why this could be a Game Changer**: Imagine QUIC in the payment platform applications and fintech domain.
- **Example**: Worldline Platform Product, since the product is web application based on AWS cloud
- **Further details inside the repository**: All the code and ReadMe can be found inside quic-lab
- **Summary**: QUIC + AWS + Terrafform + Docker + Nginx can be of a decent combination for the clean deployments of the daily transactions.
